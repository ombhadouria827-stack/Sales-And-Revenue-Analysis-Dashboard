# 📊 Sales and Revenue Analysis Dashboard

## 📌 Project Overview
This repository contains my **Sales and Revenue Analysis Project**, developed using **Power BI**.  
The project focuses on building an **interactive dashboard** that provides clear insights into business performance through key metrics and visualizations.

## 🎯 Objectives
- Present **KPIs** such as:
  - **Sum of Sales**
  - **Sum of Profit**
  - **Total Revenue**
  - **Sum of Quantity**
  - **Average Delivery Time**
- Analyze sales distribution by:
  - **Customer Segment** (Consumer, Corporate, Home Office)
  - **Region** (South, West, Central, East)
  - **Payment Mode** (Cards, COD, Online)

## 🛠️ Tools & Technologies
- **Power BI** – for interactive dashboard creation  
- **Data Source** – Superstore dataset (sample business data)  
- **Visualization Types:** Pie charts, bar charts, line graphs, maps, KPI cards
